# 결정 기록

> 결정은 여기에 남긴다. 회의·메신저에서 정한 것도 여기에 적어야 "정한 것"이다.
> **D** = 확정 · **P** = 제안(킥오프에서 확정하면 D로 옮긴다) · **O** = 미결(답이 필요하다. 추측으로 채우지 않았다).
