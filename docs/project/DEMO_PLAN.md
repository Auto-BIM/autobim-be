# 시연 계획 (16주차 라이브 시연)

> 시연 날짜·시간·장소·장비는 미결 O-01이다. 받으면 §1의 시간 배분을 고친다.

## 1. 시나리오 (약 5분 가정)

| 순서 | 화면 | 말할 것 | 시간 |
|---|---|---|---|
| 1 | 발표자료 | 문제: 2D 평면도 → BIM/3D를 손으로 만드는 비용. 목표와 범위(디지털 평면도) | 40초 |
| 2 | 웹 업로드 화면(OCI 공개 URL) | 도면 한 장을 실제로 올린다 | 20초 |
| 3 | 작업 화면 "인식 중" | 기다리는 동안 파이프라인 설명: 분할 모델(CPU) → 벽·개구부 → Plan(mm) → 3D·dxf | 30~60초 |
| 4 | 3D 뷰어 | 회전·확대, 벽 클릭(두께·종류), 문·창 구멍, "위에서" 보기 | 40초 |
| 5 | 축척·확인 필요(P1) | "축척 추정" 표시 → 건물 가로 길이 입력 → 몇 초 만에 다시 만듦(모델 재실행 없음) | 40초 |
| 6 | 다운로드 → SketchUp(미리 열어 둠) | `.dxf` 가져오기 → 벽마다 컴포넌트, 태그 | 40초 |
| 7 | 발표자료 | 평가 표(모델·시스템·실행), 한계와 다음 단계 | 50초 |

실시간 업로드가 1분을 넘기면 3단계에서 **미리 만든 작업**(같은 도면)으로 넘어간다.

## 2. 데모 세트

- [EVALUATION_PLAN](EVALUATION_PLAN.md) §6의 합격 도면 중 3~5장. 출처·공개 가능 여부는 O-07을 따른다.
- 장마다 미리 준비: 원본 이미지, 결과 파일(glb·dxf·json), 프론트 데모 모드용 폴더(FE-14), SketchUp 파일(가져온 상태로 저장), 화면 녹화 1개.
- 시연 직전 OCI에서 같은 도면을 한 번 올려 둔다(미리 만든 작업). 링크를 메모장에.

## 3. 대체 수단 (순서대로)

| 상황 | 대체 |
|---|---|
| 실시간 처리가 느림(> 60초) | 미리 만든 작업 링크로 전환 |
| OCI 접속 불가 | 노트북 로컬 실행([deploy-oci.md](../deploy-oci.md) §11) — 인터넷 불필요 |
| 노트북 실행도 실패 | 프론트 데모 모드(`/demo/:name`, 정적 파일만) |
| 브라우저·그래픽 문제 | 녹화 영상 |
| SketchUp 문제 | 미리 저장한 SketchUp 파일 열기 |
